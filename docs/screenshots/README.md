# Screenshots

Captures locales utilisees pour la QA visuelle.

- `desktop/` : captures desktop.
- `mobile/` : captures mobile.
- `motion/` : captures liees aux animations ou interactions.
- `other/` : captures de verification ponctuelles.

Les fichiers image de ce dossier sont ignores par Git lorsqu'ils ne sont pas necessaires au fonctionnement du site.
